```typescript
export function normalizeQuestionPrompt(p?: string | null): string {
  if (!p) return "";
  return p
    .trim()
    .toLowerCase()
    .replace(/[\s\r\n\t]+/g, " ")  // توحيد المسافات
    .replace(/[؟?.,!،:;ـ_—\-\(\)\[\]\{\}«»"']/g, "")  // حذف علامات الترقيم
    .replace(/[^\p{L}\p{N}\s]/gu, "");  // حذف الرموز الخاصة
}
```

function isCompleteValidQuestion(q: QuizQuestion | undefined | null): boolean {
  if (!q || !q.prompt || typeof q.prompt !== "string") return false;
  
  const prompt = q.prompt.trim();
  if (prompt.length < 8) return false;
  
  // رفض الأسئلة غير الكاملة
  if (/\b(?:ما فائدة|سؤال|Question)\b\s*$/.test(prompt)) return false;
  if (/\r?\n\s*[A-Da-dأابجده]\)\s*$/.test(prompt)) return false;
  
  // رفض الأسئلة المقطوعة (ending with prepositions or dashes)
  if (/(?:^|\s)(?:ت|لت|ي|و|ف|ب|ك|ل|ال|دون)$/.test(prompt)) return false;
  if (/[\—\-\:\/]\s*$/.test(prompt)) return false;
  
  // التحقق من الخيارات
  if (!Array.isArray(q.options) || q.options.length < 2) return false;
  for (const rawOpt of q.options) {
    if (!rawOpt || typeof rawOpt !== "string") return false;
    const opt = cleanOptionString(rawOpt);
    if (opt.length < 2) return false;
  }
  
  // التحقق من correctIndex
  if (typeof q.correctIndex !== "number" || 
      q.correctIndex < 0 || 
      q.correctIndex >= q.options.length) {
    return false;
  }
  
  return true;
}

## 7️⃣ المشاكل المكتشفة والتوصيات

### 🔴 مشاكل حرجة

#### 1. تعقيد مطابقة الأسئلة (Question Matching Complexity)
**المشكلة:** استخدام 3 طرق مختلفة للمطابقة يزيد من احتمال الأخطاء

**التوصية:**
- **الحل القصير المدى:** توثيق واضح لأولوية الطرق في كود Frontend
- **الحل الطويل المدى:** توحيد الطريقة على `originalIndex` فقط وحذف الطرق الأخرى

#### 2. التطبيع قد يسبب تصادمات (Normalization Collisions)
**المشكلة:** سؤالان مختلفان قد يصبحان متطابقين بعد التطبيع

مثال:
```
السؤال 1: "ما هي الإجابة الصحيحة؟"
السؤال 2: "ما هي الاجابة الصحيحة!"
```
بعد التطبيع: كلاهما `"ما هي الاجابة الصحيحة"`

**التوصية:**
```typescript
// إضافة hash من أول 3 خيارات لتقليل التصادمات
function makeQuestionKey(prompt: string, options: string[]): string {
  const normalizedPrompt = normalizeQuestionPrompt(prompt);
  const optionsHash = options
    .slice(0, 3)
    .map(o => normalizeQuestionPrompt(o))
    .join('|');
  return `${normalizedPrompt}::${optionsHash}`;
}
```

### 🟡 مشاكل متوسطة

#### 3. استرجاع correctCount من النسبة المئوية
**المشكلة:** إذا لم تكن `details` محفوظة، يتم استنتاج `correctCount` من `score%`

**التوصية:**
- التأكد من حفظ `details` دائماً في جدول `quiz_attempts`
- إضافة migration لملء `details` للمحاولات القديمة:

```sql
-- Migration to backfill missing details
UPDATE quiz_attempts a
SET details = (
  SELECT jsonb_agg(
    jsonb_build_object(
      'questionIndex', idx,
      'selectedOption', (a.answers->idx)::int,
      'correctOption', (q.questions->idx->'correctIndex')::int,
      'isCorrect', (a.answers->idx)::int = (q.questions->idx->'correctIndex')::int,
      'prompt', q.questions->idx->'prompt'
    )
  )
  FROM generate_series(0, jsonb_array_length(q.questions) - 1) idx
)
FROM quizzes q
WHERE a.quiz_id = q.id
  AND a.details IS NULL
  AND jsonb_array_length(a.answers) > 0;
```

#### 4. عدم وجود audit trail لتغييرات الاختبار
**المشكلة:** إذا تم تعديل سؤال بعد حل الطالب له، لا يوجد سجل للنسخة القديمة

**التوصية:**
```typescript
// إضافة جدول quiz_versions
CREATE TABLE quiz_versions (
  id SERIAL PRIMARY KEY,
  quiz_id INTEGER NOT NULL REFERENCES quizzes(id) ON DELETE CASCADE,
  version INTEGER NOT NULL,
  questions JSONB NOT NULL,
  created_at TIMESTAMP NOT NULL DEFAULT NOW(),
  UNIQUE(quiz_id, version)
);

// حفظ نسخة عند كل attempt
INSERT INTO quiz_versions (quiz_id, version, questions)
SELECT quiz_id, COALESCE(MAX(version), 0) + 1, questions
FROM quiz_attempts
WHERE quiz_id = $1
ON CONFLICT DO NOTHING;
```

#### 5. إضافة weighted scoring
**الاقتراح:** دعم أسئلة بنقاط مختلفة

// في QuizQuestion
points?: number;  // موجود لكن غير مستخدم

const totalPoints = details.reduce((sum, d, i) => {
  const points = quiz.questions[i].points || 1;
  return sum + (d.isCorrect ? points : 0);
}, 0);

const maxPoints = quiz.questions.reduce((sum, q) => sum + (q.points || 1), 0);

#### 7. Analytics Dashboard للأسئلة
**الاقتراح:** تتبع معدل الإجابة الصحيحة لكل سؤال

```sql
-- View للإحصاءات
CREATE MATERIALIZED VIEW question_analytics AS
SELECT
  q.id as quiz_id,
  q.title as quiz_title,
  question_idx,
  (details->question_idx->>'prompt')::text as prompt,
  COUNT(*) as total_attempts,
  SUM(CASE WHEN (details->question_idx->>'isCorrect')::boolean THEN 1 ELSE 0 END) as correct_count,
  ROUND(
    100.0 * SUM(CASE WHEN (details->question_idx->>'isCorrect')::boolean THEN 1 ELSE 0 END) / COUNT(*),
    2
  ) as success_rate
FROM quiz_attempts a
JOIN quizzes q ON a.quiz_id = q.id,
LATERAL jsonb_array_elements(a.details) WITH ORDINALITY AS arr(elem, question_idx)
GROUP BY q.id, q.title, question_idx, (details->question_idx->>'prompt')::text;
```
